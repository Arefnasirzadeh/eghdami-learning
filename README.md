### 🤖 اندروید
۱. روی «نصب روی اندروید» بزن تا اپ توی کروم باز بشه.
۲. روی دکمه‌ی «نصب» بزن. اگه دکمه نیومد: منوی ⋮ کروم ← «Install app / افزودن به صفحه اصلی».

### 🍎 آیفون (فقط با سافاری)
۱. روی «نصب روی آیفون» بزن و «Allow / اجازه» رو بزن.
۲. برو تنظیمات (Settings)، بالای صفحه «Profile Downloaded / نمایه دانلود شد» رو بزن.
۳. «Install / نصب» رو بزن (اگه نوشت Not Verified عادیه). آیکون EGHDAMI روی صفحه‌ی اصلی میاد.

راه دوم: سایت رو توی سافاری باز کن ← دکمه‌ی Share ⬆️ ← «Add to Home Screen / افزودن به صفحه اصلی».

> اگه از اینستاگرام یا تلگرام لینک رو باز کردی، اول «Open in browser / باز کردن در مرورگر» رو بزن.
